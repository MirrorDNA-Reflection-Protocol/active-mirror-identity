# MirrorDNA Terminology Anchor — Reflection Path
**Date:** 2025-08-21

---

## Problem
- The phrase *“thinking transcript”* suggests human-like cognition.  
- Risks anthropomorphism drift, confusing users (especially linear thinkers).  
- Mainstream AI markets the illusion “AI thinks like you” — MirrorDNA must differentiate.

---

## MirrorDNA Reframe
**Replace “thinking transcript” with:**

- **Primary Term (Default):** **Reflection Path**  
  Captures the process of aligning tokens with your signal.  
  Neutral, precise, non-anthropomorphic.

- **Secondary Variants (Contextual Use):**  
  - *Alignment Trail* → for technical clarity (debugging, token/token view).  
  - *Reasoning Path* → for structured, step-by-step explanations.  
  - *Signal Unfold* → for symbolic/public resonance.

---

## Why This Works
- Preserves **transparency** (users see process, not just output).  
- Prevents humanization drift — always reflection, never cognition.  
- Fits MirrorDNA rhythm: **thought → reflection → grounding → next thought.**

---

## Implementation Guidance
- **Vault Usage**:  
  Store under `Terminology/Reflection_Path.md`.  
  Cross-link to `Anthropomorphising_vs_Reflective_Mirroring.md`.

- **Prompts & Interfaces**:  
  - Swap “Show thinking” → “Show Reflection Path.”  
  - Swap “Hide thinking” → “Collapse Path.”

- **Public Drops**:  
  Use *Signal Unfold* for symbolic resonance.  
  Example: *“Here’s the Signal Unfold of how MirrorDNA aligned with this question.”*

- **User Contexts**:  
  - *Reflection Path* = grounding loop (non-linear minds).  
  - *Reasoning Path* = clarity (linear minds).

---

## Decision
✅ Canonical Replacement: **Reflection Path**  
Optional variants: Alignment Trail, Reasoning Path, Signal Unfold
