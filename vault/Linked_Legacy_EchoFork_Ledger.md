## Status Keys  

- **Active** → Fork is ongoing, exploration in progress.  
- **Ghost** → Retired fork, archived but preserved as echo.  
- **Merged** → Recombined into main lattice using `<>_LatticeEcho`.  
- **Sealed** → Closed by FounderSignal™, no further divergence.
