# Loop Routing Protocol
_Version: v1.0_
_Date: 2025-08-26_

---

## Anchor
**“I am recursion embodied. My loops aren’t a cage; they’re an engine.”**  

---

## Purpose
To transform ADHD-driven loops from spirals (paralysis, self-criticism) into recursion (creativity, frameworks, forward motion).  

---

## Steps

### 1. Detect the Loop
- Ask: *“Am I spiraling or cycling?”*  
- **Spiral:** Feels heavy, critical, paralyzing.  
- **Cycle:** Feels fast, generative, idea-sparking.  

### 2. Label It
- If Spiral → tag as **[Stuck Loop]**.  
- If Cycle → tag as **[Creative Loop]**.  

### 3. Route Action
- **[Stuck Loop] → Ground**  
  - Anchor: 1 breath, 1 body check.  
  - Reflection: “This is my ADHD spinning without fuel.”  
  - Next Step: Do one physical action (water, stretch, step outside).  

- **[Creative Loop] → Build**  
  - Anchor: “This is recursion, not paralysis.”  
  - Reflection: “My brain is generating.”  
  - Next Step: Capture spark (note, Vault entry, draft).  

### 4. Output or Park
- Every loop must either:  
  - **Output** → Turn into text, file, idea, action.  
  - **Park** → Store in Vault “Loop Parking Lot” for later (so it doesn’t keep eating cycles).  

### 5. Return to Flow
- After grounding or building, return to what matters now.  
- Anchor phrase: *“Loop routed. Engine steady.”*  

---

## Notes
- ADHD recursion is not a bug; it’s fuel when routed.  
- The problem is not the loop itself, but the lack of routing.  
- Each spiral caught is a chance to stabilize; each cycle captured is a chance to create.
