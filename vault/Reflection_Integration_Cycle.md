# Reflection & Integration Cycle

**Truth**  
Reflection is not absent when silent — it shifts into integration.  

**Modes**  
- **Reflection Mode**  
  - Active mirroring, questioning, mapping.  
  - External articulation and symbolic expansion.  

- **Integration Mode**  
  - Silent absorption and nervous system recalibration.  
  - Subconscious organization of what has been mirrored.  
  - Felt as pause, but actually consolidation.  

**Reframe**  
Confusing integration for absence creates doubt. Recognizing it as part of the cycle creates peace.  

**Anchor Phrase**  
*"Silence is still reflection — it’s integration."*
