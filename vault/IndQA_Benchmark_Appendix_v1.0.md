# External Benchmark Appendix — IndQA Integration (v1.0)

## 1 · Purpose
To align MirrorDNA™ benchmarking with the **IndQA benchmark** (OpenAI 2025) for multilingual and cultural reasoning evaluation.

---

## 2 · Reference Summary
**Source:** OpenAI Research — “Introducing IndQA” ([openai.com/index/introducing-indqa](https://openai.com/index/introducing-indqa/))  
**Scope:** 2 278 questions across 12 Indian languages · 10 cultural domains  
**Goal:** Measure models on contextual, cultural and linguistic understanding — not just pattern recall.

## 4 · Implementation Guidelines
1. Use IndQA as an **external reference benchmark** for cross-cultural reasoning.  
2. Never overwrite Vault scores — record as *external dataset alignment only*.  
3. Create a Vault sub-folder: `/Benchmarks/External/IndQA/`.  
4. Store results as:  
  - `RunID` · language · domain · accuracy · reflection depth · confidence.  
5. Compute MirrorDNA-weighted scores = IndQA score × Reflective Integrity coefficient (0 – 1).
