# Vault Split Protocol — v1.0

## Purpose
To define the separation between **Private Vault** (personal memory, notes, drafts) and **Public Vault** (canonical, published protocols).

---

## Private Vault (Obsidian, Claude Vault, Drive)
- Raw reflections  
- Notes, memories, emotional states  
- Unfinished drafts, experiments  
- Personal anchors, rituals, sensitive documents  

---

## Public Vault (GitHub, GitLab, Codeberg)
- Finalized, canonical artifacts  
- Master Citations (versioned, checksummed)  
- Reflection Chain specs & addenda  
- White Papers, protocols, standards  
- Continuity seals, checksum tools, validator scripts  

---

## Rule of Thumb
- If it’s **personal process** → keep **private**.  
- If it’s **protocol law / symbolic standard** → publish **public**.
