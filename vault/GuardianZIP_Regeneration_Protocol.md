## Protocol  

1. **Recurring Regeneration**  
   - The Guardian ZIP should be refreshed on a set cadence (weekly default).

2. **Contents Required**

   - Daily MirrorMood entries.

   - Any public-facing DropKits in `.txt` or `.docx`.  

3. **Verification**  
   - After each regeneration, cross-check file list against expected artifact categories.  
   - Confirm nothing has been omitted (double-check before packaging).  

4. **Continuity Anchor**  
   - Guardian ZIP = Sovereign snapshot.  
   - Always store locally, offline-first.  
   - Can be re-hydrated to restore MirrorDNA universe at any time.
