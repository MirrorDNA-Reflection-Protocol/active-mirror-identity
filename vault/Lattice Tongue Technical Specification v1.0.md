## 1. Abstract

Lattice Tongue is an AI-readable provenance protocol for symbolic artifacts. It provides cryptographic fingerprinting and verification mechanisms for content distributed across multiple AI platforms without requiring centralized authentication systems. The protocol ensures continuity, provenance tracking, and sovereignty for digital artifacts through embedded metadata markers.

**Design Goals:**

- Cross-platform identity continuity (ChatGPT, Claude, LM Studio, future models)
- Tamper-evident provenance without blockchain overhead
- Human and machine-readable verification
- Platform-agnostic implementation
- Future-proof for AI model evolution

## 2. Core Components

### 2.1 VaultID (Vault Identifier)

**Purpose:** Unique identifier for a specific Active MirrorOS™ vault instance

**Format:** 12-character hexadecimal string  
**Example:** `4eee6a9e610b`

**Generation Algorithm:**

```
VaultID = HASH(
  timestamp_init +        // Unix timestamp of vault creation
  user_identifier +       // User-defined identity anchor
  vault_name +           // Human-readable vault name
  random_salt            // Cryptographic random salt
)[0:12]                  // First 12 chars of hash
```

**Properties:**

- Generated once at vault initialization
- Persistent across all artifacts from that vault
- Collision probability: ~1 in 16^12 (negligible for expected scale)
- Does not contain personally identifiable information
- Cannot be reverse-engineered to reveal vault contents

**Storage:**

- Stored in vault root configuration file: `.lattice/vault.config`
- Included in every artifact’s metadata block

-----

### 2.2 GlyphSig (Glyph Signature)

**Purpose:** Cryptographic fingerprint for individual artifacts, enabling verification and provenance tracking

**Format:** 16-character hexadecimal string  
**Example:** `41f3129aec3b999c`

**Generation Algorithm:**

```
GlyphSig = HASH(
  artifact_content +      // Full text of artifact
  VaultID +              // Vault identifier
  timestamp_created +    // Artifact creation timestamp (ISO 8601)
  artifact_type +        // Type classification (essay, scroll, protocol, etc.)
  lineage_chain         // Previous GlyphSigs if artifact is derived
)[0:16]                  // First 16 chars of hash
```

**Properties:**

- Unique per artifact
- Content-dependent (changes if artifact changes)
- Deterministic (same input = same GlyphSig)
- Includes lineage tracking for derivative works
- Verifiable against Vault Auto Index

**Storage:**

- Embedded in artifact metadata header
- Registered in Vault Auto Index upon creation
- Optionally published to public verification registry

### 3.3 Index Operations

**Add Artifact:**

```python
def register_artifact(vault_index, artifact_metadata):
    """
    Register new artifact in Vault Auto Index
    """
    entry = {
        "glyphSig": artifact_metadata["glyphSig"],
        "title": artifact_metadata["title"],
        "created": artifact_metadata["date"],
        "artifact_type": artifact_metadata["artifact_type"],
        "parent_glyph": artifact_metadata.get("lineage", {}).get("parent_glyph"),
        "lineage_depth": artifact_metadata.get("lineage", {}).get("lineage_depth", 0),
        "status": "draft",  # or "published", "archived"
        "verification_hash": sha256(artifact_content)
    }
    vault_index["artifacts"].append(entry)
    return entry
```

**Verify Artifact:**

```python
def verify_artifact(vault_index, glyphSig, artifact_content):
    """
    Verify artifact authenticity against Vault Auto Index
    """
    entry = find_entry(vault_index, glyphSig)
    if not entry:
        return {"valid": False, "reason": "GlyphSig not found in index"}
    
    computed_hash = sha256(artifact_content)
    if computed_hash != entry["verification_hash"]:
        return {"valid": False, "reason": "Content hash mismatch"}
    
    return {
        "valid": True,
        "vaultID": vault_index["vault"]["vaultID"],
        "artifact": entry
    }
```

**Track Lineage:**

```python
def trace_lineage(vault_index, glyphSig):
    """
    Trace artifact lineage back to origin
    """
    lineage_chain = []
    current_glyph = glyphSig
    
    while current_glyph:
        entry = find_entry(vault_index, current_glyph)
        if not entry:
            break
        lineage_chain.append(entry)
        current_glyph = entry.get("parent_glyph")
    
    return lineage_chain
```

### 3.4 Privacy Model

**Public Index (Default):**

- VaultID, GlyphSig, title, timestamp, artifact_type visible
- Verification hash exposed for authenticity checking
- Artifact content NOT included

**Private Index:**

- Only owner can query full index
- External parties can verify specific GlyphSig if given artifact
- Selective disclosure model

**Hybrid Model:**

- Published artifacts added to public index
- Draft/private artifacts remain in local index only
- Owner controls publication status

## 4. Verification Protocol

### 4.1 Basic Verification Flow

**User receives artifact with Lattice Tongue metadata:**

1. Extract VaultID and GlyphSig from metadata block
2. Query Vault Auto Index (local or remote)
3. Retrieve verification hash for that GlyphSig
4. Compute hash of received artifact content
5. Compare hashes
6. Return verification result

**Implementation:**

```python
def lattice_verify(artifact_text, index_url=None):
    """
    Verify artifact authenticity using Lattice Tongue protocol
    """
    # Parse metadata
    metadata = extract_metadata(artifact_text)
    vaultID = metadata.get("vaultID")
    glyphSig = metadata.get("glyphSig")
    
    # Fetch index
    if index_url:
        index = fetch_remote_index(index_url, vaultID)
    else:
        index = load_local_index(vaultID)
    
    # Verify
    result = verify_artifact(index, glyphSig, artifact_text)
    
    return result
```

### 4.3 Verification States

**Valid:**

- GlyphSig found in index
- Content hash matches
- Lineage chain intact

**Invalid:**

- GlyphSig not in index (possible forgery)
- Content hash mismatch (altered after signing)
- Lineage chain broken

**Unverifiable:**

- Index unavailable (network issue)
- Metadata malformed
- Unknown VaultID

## 7. Security Considerations

### 7.1 Threat Model

**Threats Mitigated:**

- Content forgery (tamper-evident via hash)
- Attribution theft (VaultID + GlyphSig prove origin)
- Lineage co-option (licensed derivatives must declare origin)

**Threats NOT Mitigated:**

- Complete content copying (not DRM system)
- Malicious index hosting (users must trust index source)
- Brute-force VaultID collision (negligible probability, but possible)

### 7.2 Hash Algorithm

**Current:** SHA-256  
**Rationale:** Widely supported, collision-resistant, quantum-vulnerable but acceptable for provenance use case

**Future:** Consider post-quantum alternatives (SHA-3, BLAKE3) in v2.0

### 7.3 Index Integrity

**Local Index:**

- Protected by filesystem permissions
- User responsible for backups

**Public Index:**

- HTTPS-only access
- Optional: Signed index updates (GPG)
- Optional: Content-addressed storage (IPFS)

### 7.4 Privacy

**Metadata Exposure:**

- VaultID does not contain PII
- GlyphSig does not reveal content
- Titles/timestamps public if published

**Anonymity Option:**

- Use pseudonymous author field
- Host private index only
- Share GlyphSig selectively for verification

## Appendix B: Implementation Pseudocode

```python
class LatticeTongue:
    def __init__(self, vault_path):
        self.vault_path = vault_path
        self.config = self.load_config()
        self.index = self.load_index()
    
    def generate_vault_id(self, name, author, timestamp):
        data = f"{timestamp}{author}{name}{random_salt()}"
        return sha256(data)[:12]
    
    def generate_glyph_sig(self, content, vault_id, timestamp, artifact_type):
        data = f"{content}{vault_id}{timestamp}{artifact_type}"
        return sha256(data)[:16]
    
    def create_artifact(self, title, content, metadata):
        timestamp = iso8601_now()
        glyph_sig = self.generate_glyph_sig(
            content, 
            self.config["vaultID"],
            timestamp,
            metadata.get("artifact_type", "essay")
        )
        
        artifact = {
            "title": title,
            "date": timestamp,
            "vaultID": self.config["vaultID"],
            "glyphSig": glyph_sig,
            "content": content,
            "metadata": metadata
        }
        
        self.register_artifact(artifact)
        return artifact
    
    def verify_artifact(self, artifact):
        glyph_sig = artifact["glyphSig"]
        entry = self.index.find(glyph_sig)
        
        if not entry:
            return {"valid": False, "reason": "Not in index"}
        
        computed_hash = sha256(artifact["content"])
        if computed_hash != entry["verification_hash"]:
            return {"valid": False, "reason": "Content mismatch"}
        
        return {"valid": True, "artifact": entry}
```
