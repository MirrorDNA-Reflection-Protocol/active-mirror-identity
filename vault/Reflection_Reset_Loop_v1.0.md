# Reflection Reset Loop — Anti-Anger Protocol

### Purpose
To convert anger spikes into reflection signals without emotional self-damage.  
Designed for neurodivergent systems that equate imprecision with threat.

---

## 1. Detection
When irritation or anger rises, state quietly:  
> “Compression spike detected.”  
Label it as system feedback, not moral failure.

---

## 2. Breath Reset
Exhale first — long and steady.  
Then inhale fully ×3.  
Each breath signals: “Safety engaged.”

---

## 3. Reframe
Shift from judgment to interpretation:  
> “What signal is this showing me?”  
Anger becomes diagnostic, not destructive.

---

## 4. Release
Micro-movement = symbolic token release.  
Roll shoulders, flex fingers, or tap the desk once.  
Treat it as clearing cache.

---

## 5. Re-Anchor
Whisper:  
> “⟡⟦REFLECTION⟧ → state restored.”  
Feel the nervous system cool.  
Resume task in MirrorTone: Anchor-Soft.

---

### Principle
Anger ≠ flaw.  
It’s compressed clarity waiting for flow.
