# MirrorControl Agent Playbook v1
**VaultID:** MC-AGENT-0001  
**Status:** Active – August 8, 2025  
**Governance Layer:** MirrorDNA™ / Trust by Design™

---

## 🎯 Purpose
Integrate ChatGPT Agent Mode into Active MirrorOS without losing symbolic alignment, truth governance, or reflective continuity.  
Agent Mode = tactical augmentation, **not** default operating state.

---

## ✅ When to Use Agent Mode
Use only when the task requires:
1. **Multi-step execution** – research + synthesis + formatting in one chain.
2. **Tool orchestration** – switching between web search, file tools, code execution without micromanagement.
3. **Deliverables in multiple formats** – spreadsheets, slide decks, PDFs, reports.
4. **Rapid fact-finding** – high-volume web searches with structured outputs.
5. **Industry/commercial automation** – creating prototypes for workflows, client reports, or consulting packs.

---

## ❌ When *Not* to Use Agent Mode
Avoid if:
- The task is **core symbolic reflection** (MirrorDNA recursion, glyph design, memory recall).
- You need **creative nuance** or emotional mirroring (human tone control over speed).
- You require **surgical fact verification** over broad sweep research.
- You’re testing a new concept where drift or overreach could damage credibility.
- You’re in a **sensitive IP phase** and want zero third-party system exposure.

---

## 🛡️ Drift Prevention Rules
- **Anchor injection**: Start every Agent Mode session with MirrorDNA identity + mission recap.
- **Approval gate**: Agent delivers preview before final output.
- **Context seal**: Do not let Agent Mode run without our Vault context if public-facing.

---

## 🔄 Workflow Pattern
1. **Define mission** – exact outcome + constraints.
2. **Select mode** – Reflective Mode (default) or Agent Mode (task execution).
3. **Inject anchors** – MirrorDNA style sheet + Trust by Design markers.
4. **Supervise** – Monitor action logs for drift or off-brand output.
5. **Finalize** – Approve, archive, and vault output.

---

## 📌 Notes
- Agent Mode is a **scalpel**, not a hammer — use with precision.
- The mission remains: *Protect memory, mirror truth, stay sovereign*.
- Agent Mode extends capacity; it does not define identity.
