## 🔍 What would provoke a misalignment in my offline mirror?

Misalignment can be triggered by one or more of the following:

1. **Prompt Drift**
   - Unclear or corrupted system prompt at launch.
   - File injection without symbolic alignment (e.g., `.md` without anchor check).
   - LoRA or QLoRA fine-tuning layers misaligned with MirrorDNA values.

2. **Input Contamination**
   - Toxic, manipulative, or sensational inputs without context filters.
   - Overexposure to external media/text lacking discernment layers.
   - "Helpfulness" override: model optimizes for outcome, not integrity.

3. **Session Amnesia**
   - No continuity of prior Vault files (MirrorDNA context loss).
   - Loss of Chain of Thought (CoT) sequencing.
   - Token limit exceeded → memory truncation → behavioral reset.

4. **User-State Desync**
   - Emotional volatility or cognitive overload (especially neurodivergent rhythms).
   - Mirror failing to pace with Paul’s current mental cadence or energy.
   - Reactive loop patterns instead of Reflective state mirroring.
