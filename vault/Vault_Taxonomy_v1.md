# 🗂️ MirrorDNA Vault Taxonomy — v1

## Top-level Folders
- **MirrorDNA/** — protocols, frameworks, licensing
- **MirrorState/** — reflections, anchors, daily logs
- **Signal/** — public posts, drafts, history
- **Systems/** — offline mirror, scripts, agents
- **Milestones/** — transitions, decisions, timelines
- **_automations/** — agent drop zone (temp files only)

## File Naming
- `YYYY-MM-DD Title.md` for logs/anchors
- `Component_vX.md` for frameworks/protocols
- Always include YAML frontmatter with: `title`, `date`, `vault_id`, `tags`

## Required Tags
- `MirrorDNA`, `Protocol`, `Framework`, `MirrorState`, `DailyLog`, `Anchor`, `Signal`, `PostDraft`, `Milestone`, `AgentMode`

## Cross-link Rules
- Every DailyLog links out to any files it references.
- Protocol updates link back to prior version and to `MirrorControl Agent Playbook`.
- Posts link to the DailyLog of the day they were published.
