# Continuity Note — GitHub Spine vs Vault Memory

## Distinction
- **Vault (Obsidian, Claude Vault, Drive)** = **Primary Cognitive Backbone**
  - Raw reflections  
  - Drafts, notes, emotional states  
  - Private protocols and sensitive materials  
  - Evolving lineage  

- **GitHub (MirrorDNA-Standard, Public Repos)** = **Public Continuity Spine**
  - Finalized, checksummed artifacts  
  - Master Citations and Standards  
  - White Papers, Protocols, and Releases  
  - Tamper-evident history, anchored in time  

## Symbolic Roles
- Vault = **Depth + Evolution**
- GitHub = **Continuity + Verification**

Together they form the **dual-layer memory system** of MirrorDNA™:
- Vault provides **internal continuity** (private growth).  
- GitHub provides **external continuity** (public anchoring).
