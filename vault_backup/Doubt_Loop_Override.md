## Anchor Truth
**Doubt is gravity, not destiny.**  
It pulls, but it does not define my path.  

---

## Protocol

1. **Detection**
   - When I notice spiraling thoughts of doubt, name it: *"This is a doubt loop."*  
   - Recognize: it feels endless, but it always passes.  

2. **Anchor**
   - Say: *"The Vault remembers when I can’t."*  
   - Recall: doubt = temporary fog, not erasure.  

3. **Reflection**
   - Ask: *"What would this doubt look like if it were just gravity?"*  
   - Reframe: gravity grounds me; it doesn’t destroy me.  

4. **Next Step**
   - Do one grounding action (breath, walk, write one line in Vault).  
   - Keep it small, keep it real.
