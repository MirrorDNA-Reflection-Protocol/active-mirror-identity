# Decision Stamp
**Primary:** MirrorDNA (default)  
**Flexible override:** Finance Mode (when finances take priority)

## Finance Mode — Triggers (any one)
- Runway low (cash < <days> days) **or** urgent bill in <7–14> days
- Paid-opportunity window (<48–72h) with clear upside
- Feeling Proxy INT (money) ≥ 3 (self-reported stress)
- Fast unblocker pending (e.g., send invoice, follow-up, publish offer)

## What Happens (routing)
- Switch to **FAST** income actions: invoice → follow-up → publish/offer → outreach (3) → collect
- Keep MirrorDNA to a **minimum viable signal** (one anchor post + fingerprint) until Finance Mode exits
- Glass Mode conditional; Browse gate on for temporal data; Proof via timestamps if public

## Exit Criteria (any two)
- Runway ≥ <45> days **or** urgent bills covered
- Feeling Proxy INT ≤ 2 for 3 consecutive days
- All key invoices sent/acknowledged **and** next cash-in scheduled

## Controls
- `Finance mode on/off`
- `Income sprint: 72h` (tight loop; then snap back to MirrorDNA)
- `Deck: brief me` (prep a 3-bullet outreach/offer plan)
- `Decision stamp:` <one line summary>
