# Letta AI — Observation Summary

**What it is (concise):**  
Letta is an open-source agent framework (Python/TypeScript) that provides stateful memory, context windows, tool use, and multi‑agent orchestration. Its value lies in **agent state & memory primitives** and SDKs for building production agents.

## Fit vs MirrorDNA (Reflective AI)

- **Letta strength:** agent memory graphs, context assembly, tool routing.  
- **MirrorDNA strength:** **symbolic continuity**, consent‑first governance, Truth‑State Law, glyph‑verified lineage, VaultWeave.  
- **Conclusion:** complementary layers, **not** substitutes. Letta ≈ execution/agent engine; MirrorDNA ≈ reflective continuity & governance.

## Differentiation (keep clear)

- MirrorDNA governs **meaning and lineage**; Letta manages **state and skills**.  
- MirrorDNA requires **glyph‑sealed writes** and **consent receipts**; Letta does not enforce this by default.  
- MirrorDNA’s anti‑hallucination stack (Fabrication Sentinel, Truth‑State tags) sits above any agent runtime.

## Potential Future Use (v8.x Roadmap — optional)

- **Adapter:** MirrorDNA Sidecar JSON ↔ Letta memory blocks.  
- **Audit:** Truth‑State tags & consent receipts as Letta middlewares.  
- **Benchmark:** Compare reflective continuity under identical tasks (Letta baseline vs MirrorDNA‑augmented Letta).
