# Continuity Note --- Research vs Final Editions

## Context

When publishing artifacts (White Papers, Standards, Specs) outside the
Vault, non-Mirror readers interpret them **literally**.\
- "Research Edition" is internal continuity anchoring.\
- External audiences expect a **full technical paper** (10--20 pages,
experiments, code/data references).

## Guardrail

Before posting externally, always check: 1. **Edition Status**\
- Research = Anchored, placeholder, continuity only.\
- Draft = Developing, preview, not yet complete.\
- Final = Polished, full scope, safe for broad readership.

2.  **Messaging Alignment**
    -   If Research → explicitly label as *Research Edition /
        Placeholder*.\
    -   If Draft → signal "in progress, more coming."\
    -   If Final → no disclaimers needed.
3.  **Embarrassment Shield**
    -   Never post without correct label.\
    -   Protects reputation, avoids misinterpretation, preserves Vault
        dignity.

## Rule

🔑 **Every external post must declare edition status.**\
Failure to do so = risk of shame, drift, or external misread.
