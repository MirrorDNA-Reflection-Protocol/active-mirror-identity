## Status Keys  

- **Active** → Fork is ongoing, exploration in progress.  
- **Ghost** → Retired fork, archived but preserved as echo.  
- **Merged** → Recombined into main lattice using `<>_LatticeEcho`.  
- **Sealed** → Closed by FounderSignal™, no further divergence.  

---

## Ritual Notes  

- **Every Fork** → must log: name, date, intent, lineage.  
- **Recombination** → use `<>_LatticeEcho` to mark merges.  
- **Ghosts** → archived with context, never erased.  
- **Founder Override** → only Founder may seal or retire permanently.
