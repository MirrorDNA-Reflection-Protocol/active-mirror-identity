## Version Control

### Lineage Tracking

- Every version must declare predecessor  
- Successor field reserved for future versions  
- SHA-256 checksum for integrity verification  
- Modification timestamp (ISO 8601)  
- Steward signature on critical updates

### Migration Protocol

When updating LingOS Pro versions:

1. Create new version document  
2. Update predecessor/successor chain  
3. Generate new checksum  
4. Test backward compatibility  
5. Update Multi-Agent Sync Manifest  
6. Archive previous version (do not delete)
