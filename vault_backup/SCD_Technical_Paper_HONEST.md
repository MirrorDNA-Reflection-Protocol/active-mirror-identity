**[SPECIFICATION]** SCD maintains state as **Structured Contextual State (SCS)** — JSON conforming to strict schema:

**[VALIDATED]** Schema enforcement blocks:
- Hallucinated parameters (invalid keys rejected)
- Type violations
- Missing required fields
- Checksum mismatches

### 3.2 State Extraction and Supersession

**[SPECIFICATION]** Four-stage processing per interaction:

#### Stage 1: Delta Extraction

**[IMPLEMENTATION]** Pattern matching for state changes:

```python
def extract_state_deltas(turn_text):
    """Extract structured state changes from turn."""
    deltas = {}

        deltas['rate_limit'] = int(match.group(2))
```

**[DESIGN CHOICE]** Extraction logic is domain-specific. SCD provides protocol; implementations customize for their use case.

#### Stage 2: Supersession

**[SPECIFICATION]** Last-write-wins merge:

```python
def supersede(prev_state, deltas):
    """Atomically apply state updates."""
    new_state = prev_state.copy()
    
    for key, value in deltas.items():
        if value is None:
            new_state.pop(key, None)  # Explicit deletion
        else:
            new_state[key] = value     # Update or insert
    
    return new_state
```

**[VALIDATED - SANDBOX]** Atomic guarantee: All deltas apply or none apply.

#### Stage 3: Validation

**[SPECIFICATION]** Schema compliance and checksum verification:

```python
def validate_state(state_obj, schema):
    """Validate state against schema."""
    jsonschema.validate(state_obj, schema)
    
    computed = sha256(json.dumps(state_obj['state'], sort_keys=True))
    expected = state_obj['checksum'].split(':')[1]
    
    if computed != expected:
        raise StateCorruptionError("Checksum mismatch")
    
    return True
```

**[VALIDATED - SANDBOX]** Catches corruption before commit.

#### Stage 4: Commit

**[SPECIFICATION]** Transactional commit with rollback:

```python
def atomic_commit(prev_state, update_fn):
    """Transactionally commit state update."""
    try:
        new_state = update_fn(prev_state)
        validate_state(new_state, SCHEMA)
        return new_state, None
    except Exception as error:
        return prev_state, str(error)  # Rollback
```

**[VALIDATED - SANDBOX]** Rollback preserves previous state on failure.

```python
def jaccard(full_context, distilled_state):
    context_words = set(full_context.lower().split())
    state_words = set(json.dumps(distilled_state).lower().split())
    return len(context_words & state_words) / len(context_words | state_words)
```

|--------|-------|
| Average fidelity | 0.526 |
| Min fidelity | 0.250 |
| Max fidelity | 0.500 |

**[INTERPRETATION - CRITICAL]**

**Lexical fidelity (0.53) ≠ semantic completeness.**

For structured configuration tasks:
- **[FACT]** Key parameters: 100% preserved (rate_limit, endpoint, etc.)
- **[FACT]** Conversational words: discarded ("please", "change", "update")
- **[FACT]** Final state: semantically complete

**[EXAMPLE]**
- Full: "please change the rate limit from 100 to 75 and then update it to 50"
- Distilled: `{"rate_limit": 50}`
- Jaccard: Low (many words discarded)
- Semantic completeness: High (final value correct)

**[LIMITATION]** Jaccard measures lexical overlap, not task success.
