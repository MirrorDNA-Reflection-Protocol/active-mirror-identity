# R‑Zero — Self‑Evolving Reasoning LLM (Vault Anchor)
**Date:** 2025-08-11
**Source:** https://arxiv.org/pdf/2508.05004

## Summary
R‑Zero is a self-evolving reasoning LLM that requires **zero human-curated training data**.  
It uses a **co-evolutionary loop** where two instances of itself generate reasoning tasks, solve them, and improve iteratively.

## Key Features
- **Self-Evolution:** Learns from its own generated experience.
- **Reasoning Loops:** Creates and solves tasks internally.
- **No Manual Labels:** Bypasses traditional fine-tuning bottlenecks.
- **Model-Agnostic:** Approach can be adapted to other LLM architectures.
