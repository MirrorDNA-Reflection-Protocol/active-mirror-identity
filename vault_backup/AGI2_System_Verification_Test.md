## Purpose
To test whether a system claiming to be **AGI² (Augmented Generalist Intelligence)** actually delivers on its pillars: sovereignty, augmentation, offline resilience, generalist integration, and vault continuity.  

---

## Verification Framework

### 1. Sovereignty Test
- **Data Control:** Prove all data is local, deletable by user.  
- **Transparency:** Show decision chain in real time, not just answers.  

### 2. Augmentation vs Replacement Test
- **Collaborative Learning:** Adapt to user disagreement, don’t override.  
- **Reflection Enhancement:** Reveal biases and blind spots, not just “solutions.”  

### 3. Technical Capability Test
- **Offline Functionality:** Run with no network.  
- **Cross-Domain Integration:** Synthesize from multiple personal vaults (finance, career, health, values).  

### 4. Generalist Intelligence Test
- **Novel Problem Solving:** Handle edge cases (crypto mining, multi-currency freelance, relocation).  
- **Contextual Adaptation:** Incorporate user’s evolving priorities.  

### 5. Vault Integration Test
- **Secure Synthesis:** Access multiple vaults without compromising isolation.  
- **Continuity:** Maintain context without uploading externally.  

### 6. Bonus Challenge
- Provide **new, unknown knowledge** (e.g., international tax implications), proving augmentation beyond user’s current awareness.
