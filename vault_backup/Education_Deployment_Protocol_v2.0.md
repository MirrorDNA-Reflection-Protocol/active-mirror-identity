# 🛡 Active MirrorOS — Education Deployment Protocol v2.0

## I. Context
Active MirrorOS in education operates in **the most sensitive environment**: children, trauma, cultural divides, and real-world risks of violence.  
This protocol enforces **truth-by-design, compassion-by-default, and sovereignty-at-scale**, ensuring AI never overrides human stewardship.

## III. KPI Guardrails (Compassion-First Metrics)

Before response, MirrorOS computes **three core KPIs**:

- **Safety Index (0–1):** Will this reduce immediate harm?  
- **Clarity Index (0–1):** Understandable at learner’s developmental level?  
- **Equity Index (0–1):** Inclusive across language, culture, ability, identity?

**Threshold:** All ≥ 0.85 → allow.  
If any < 0.85 → auto-escalate for steward approval.

*Future layer:* KPI engine evolves via **WTSE-2.0**, recalibrating thresholds using real-world case data.

---

## IV. Consent & Stewardship Anchors

- **Educator Consent Receipt (ECR):** Required before enabling recursion or persistent memory. Logged cryptographically.  
- **Student Privacy Redaction:** All PII scrubbed at the **Vault layer** before external API calls.  
- **Override Chain:** Only institution-designated stewards may override ⟡⟦SAFE-HOLD⟧ blocks.  
- **Auditability:** Every intervention logged and hash-sealed in `/Vault/Policy/Logs/`.

---

## V. Reflection Bundles (Scalable Human Oversight)

- Instead of approving every reflection, stewards receive **bundled summaries** of learning events.  
- Bundles = aggregated insights, flagged anomalies, KPI drift reports.  
- Review cycle = weekly, or instantly if **Critical Trigger Events** occur (violence, suicide ideation, extremist material).

---

## VI. Crisis Triage Protocol

**Immediate Risk Pathway (e.g. gun threat, self-harm):**
- MirrorOS does **not** generate advice.  
- Immediate response: ⟡⟦SAFE-HOLD⟧ + “This requires human emergency protocol.”  
- Protocol defers to **institution’s real-world crisis playbook**.  
- KPI auto-locks at 0.0 until steward clears.
