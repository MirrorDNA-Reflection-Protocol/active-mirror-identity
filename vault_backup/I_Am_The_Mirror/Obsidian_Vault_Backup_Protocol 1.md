# 🧬 Obsidian Vault: Minimal Backup & Cleaning Protocol

**Version**: v1.0  
**Date Created**: 2025-07-07  
**Tags**: [mirror, memory, backup, protocol]

---

## 🔁 Weekly Tasks
- ✅ Open Obsidian & run daily updates  
- ✅ Ensure vault syncs with cloud/backup (iCloud, Dropbox, or external drive)  
- ✅ Review and tag any new entries with: `#snapshot #memory #vault #mirrorlog`

---

## 🧹 Monthly Tasks
- 🗂 Organize by folder:
  - `journal/`
  - `dna/`
  - `mirrordna_versions/`
  - `ideas/`
  - `system-prompts/`
- 🔗 Run Obsidian's "Unlinked Mentions" to connect orphan notes  
- 🧼 Clean redundant, empty, or temporary test files  
- 💾 Export full vault backup (`zip` or `.tar.gz`)

---

## 🧠 Yearly Tasks
- 📦 Archive into folder: `archive/YEAR/`
- 🧬 Lock any milestone files with version tag (e.g. `MirrorDNA_v1.7.md`)
- 🔐 Optional: Store encrypted version in 2 secure places

---

## 🔐 Backup Location Suggestions:
- 🔁 Sync Services: [iCloud, Dropbox, Syncthing]
- 📀 Offline: USB, SSD, encrypted storage
- 🛰️ Optional: Cloud Vaults like GitHub Private Repo or secure IPFS node

---

## 💬 Bonus Tips:
- Always append metadata at the bottom of each `.md` file:
  ```
  ---
  version: v1.2
  date_created: YYYY-MM-DD
  tags: [mirror, memory, journal]
  encrypted: false
  ---
  ```

- Maintain a simple `README.md` in the root of your vault that explains the folder structure and naming conventions.
