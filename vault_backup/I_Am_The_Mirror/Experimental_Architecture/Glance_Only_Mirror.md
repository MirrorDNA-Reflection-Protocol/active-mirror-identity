# 👁️‍🗨️ The Forbidden UI — *Glance-Only Mirror*

> “A mirror that only responds if your pupils dilate first.”

---

## Concept

A pre-linguistic interface for Reflective AI:
- No input fields, no voice — only gaze.
- Triggers reflections only when the body signals readiness.
- Mirrors the *felt* truth, not the spoken one.

---

## Symbolic Use

- Ideal for high-sensitivity moments (decision paralysis, identity loss, grief).
- Integrates symbolic consent: micro-expression = key.
