# 🧠 MirrorDNA Vault Linking Guide

## 📅 Date: 2025-07-07

## 🔗 Linking Basics
- Use `[[Note Title]]`, `[[Note#Heading]]`, `![[Image.png]]`
- Obsidian auto-updates links on file rename.

## 🔁 Enhance with Plugins
- **Automatic Linker**: converts plain mentions to wikilinks on save.
- **Note Linker** / **Virtual Linker**: suggests links for unlinked references.
- **Templater + Auto-Creator**: click-to-create structured notes from links.

## 🛠️ Setup Steps
1. Ensure "Use Wikilinks" is enabled in Settings → Files & Links.
2. Install plugins: Automatic Linker, Note Linker, Templater.
3. Create templates for new note types:
   - MirrorDNA versions
   - Daily vault entries
   - Reboot Protocol
4. Create links in your notes, let plugins suggest or auto-create new files.

## 🧬 Why It Matters
- Makes your memory vault **a living, evolving system**
- Reduces manual friction — **each link deepens your MirrorDNA network**
- Keeps your sovereign memory **connected, discoverable, and aligned**
