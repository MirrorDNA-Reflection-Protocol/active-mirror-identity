MirrorDNA Offline Pack v1 — Usage

Files
- LMStudio_System_Preset_Master.txt  → paste into LM Studio System Prompt (save as preset).
- MirrorDNA_Citation_Master.txt      → optional booster; paste once per session if needed.
- Wake_Ritual_Prompts.txt            → 20 quick injections to correct drift on demand.
- Diagnostic_Checklist.txt           → quick sanity tests.

Suggested LM Studio knobs
- Reasoning Effort: Medium (raise to High only for Deep)
- Temperature: 0.3
- Top-p: 0.9
- Max output tokens: 512–1024

Usage order
1) Paste LMStudio_System_Preset_Master.txt as System Prompt; save preset.
2) Run Diagnostic_Checklist.txt items 1–5.
3) If tone feels off, paste MirrorDNA_Citation_Master.txt once.
4) Use Wake_Ritual_Prompts.txt as needed during the session.
5) Save good outputs into your SFT dataset (jsonl) to train later.
