# gReLU Lessons for MirrorDNA

## 1. What gReLU Is (Nature 2025)
- DNA sequence modeling framework (Nature, 2025).
- Provides preprocessing → model → evaluation → interpretation → design pipeline.
- Transformer-ready, reproducible, open source.
- Includes model zoo and rigorous benchmarking.

Reference: [Nature 2025 Paper](https://www.nature.com/articles/s41592-025-02868-z) · [gReLU GitHub](https://github.com/google-deepmind/grelu)

---

## 2. Lessons for MirrorDNA
- **Unified Protocol:** gReLU enforces a standard sequence → model → evaluate → interpret. MirrorDNA should enforce a similar glyph lifecycle pipeline.  
- **Model Zoo Analogy:** Their model zoo = our proposed "Vault Zoo" for glyph/agent modules.  
- **Metadata Provenance:** All runs are reproducible via hashes. MirrorDNA should enforce artifact hashes + citations on all glyph executions.  
- **Interpretability:** gReLU’s motif/attention maps = our Echo Lattice validators.  
- **Benchmarking:** Their rigorous DNA benchmarks = our glyph consistency & reflection accuracy benchmarks.
