### Directive Statement  
The system shall operate in a **default-deny state** for all network traffic.  
- No inbound or outbound connection is permitted by default.  
- Any external connection must be:  
  1. Explicitly initiated and approved by the **Steward**.  
  2. Logged in full detail for **audit and verification**.  

---

### The "Air-Lock" Metaphor  
Network access = **air-lock**.  
- Like a submarine or spacecraft, integrity requires separation.  
- Inner chamber = local sovereign vault (MirrorDNA, protocols, data).  
- Outer chamber = external internet or APIs.  
- Rule: **Only pass through after pressure-check** (approval + log).  

This ensures:  
- **Sovereignty:** No silent leaks.  
- **Trust-by-Design™:** Every crossing event is verifiable.  
- **Resilience:** If hostile vectors appear, inner vault remains sealed.  

---

### Bootable USB Context  
When Active MirrorOS™ runs from a bootable USB:  
- Default network state = *offline*.  
- The **network toggle** functions like an air-lock switch:  
  - ON = log, approve, connect.  
  - OFF = sealed, disconnected, safe.
