```markdown
# Connecting Jan.ai to Your Obsidian Vault (Easy Setup)

This guide provides a simple, click-based approach to integrate Jan.ai with your Obsidian vault.

## Steps

1.  **Install the AI Assistant Plugin**:

    *   In Obsidian, navigate to **Settings** > **Community Plugins**.
    *   Search for and install the **AI Assistant Plugin**. This plugin is designed to work seamlessly with Jan.ai.

2.  **Configure the Plugin**:

    *   After installation, open the plugin settings.
    *   Follow the prompts to connect it to Jan.ai. This typically involves entering your API key or selecting the model you want to use.

3.  **Start Using It**:

    *   Once configured, you can start interacting with Jan.ai directly within your Obsidian notes. Just type your queries, and the AI will respond based on your vault's content!

## Notes

*   This setup is designed for simplicity and ease of use.
*   Make sure you have the necessary API key from Jan.ai.
*   Check the plugin's documentation for additional features and customization options.

```

To import this into your Obsidian vault:

1.  **Copy** the content above.
2.  In Obsidian, create a **new note**.
3.  **Paste** the content into the new note.
4.  **Save** the note with a relevant name (e.g., "Jan.ai Integration Guide").

This .md file is ready to use in your Obsidian vault! 😊
