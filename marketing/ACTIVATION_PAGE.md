## Design principles

- No modals, pop-ups, or newsletter gates
- No dark patterns
- Explicit choice at every step
- Visible scope — the user knows what they're enabling
- Mobile-first vertical layout
- Loads in under 2 seconds
- No JavaScript required for core content

## Trust signals on page

- Link to public GitHub repo (inspectable contract)
- Link to Chetana (trust/safety proof)
- Signed provenance for any demo outputs
- No tracking beyond basic analytics with disclosure
