Common Questions

How is this different from platform memory?
Platform memory is stored on their servers and can be wiped or changed without warning. Your MIRROR SEED is a file you own — save it anywhere. No platform can take it away.

Does AI permanently remember me?
The seed works for the entire conversation. For new chats, paste it again. Some AIs (like Claude) may remember across sessions, but your file is the backup.

Which AIs work with this?
All of them. ChatGPT, Claude, Gemini, DeepSeek, Grok, Llama, Mistral — any AI that accepts text input.

Is my data stored anywhere?
No. Everything happens in your browser. We don't collect, store, or transmit any information. The file only exists when you download it.
