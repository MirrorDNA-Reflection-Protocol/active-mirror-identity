What is a Mirror Seed?

A portable identity file (Markdown) that you can paste into any AI (ChatGPT, Claude, etc.) to instantly align it with your context, style, and memory.

Why is it "Signed"?

We embed a SHA-256 checksum in the file header. This allows you to verify later that the file hasn't been accidentally edited or corrupted.

Is this compatible with all AIs?

Yes. The seed is just text (Markdown). The "Encryption" is for verification only—the content itself is readable by any LLM.

🔒 Zero-Data Privacy Guarantee

This tool runs 100% in your browser.

  • No data is sent to any server.
  • No cookies are used for tracking.
  • We do not store your seed.

The SHA-256 calculation happens locally using the Web Crypto API. You can disconnect from the internet and this tool will still work perfectly.
