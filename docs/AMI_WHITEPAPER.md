## Abstract
As AI systems move from "Chatbots" to "Agents" and "Digital Twins", the need for a **Sovereign, Portable, and Continuous** identity layer becomes critical. Current memory systems (ChatGPT Memory, etc.) are siloed, opaque, and rented. **AMI (Active Mirror Identity)** is an open protocol for defining an identity kernel that survives across platforms (`v0.1`), enforces truth via SCD (`Module A`), and communicates via LingOS (`Module C`).
