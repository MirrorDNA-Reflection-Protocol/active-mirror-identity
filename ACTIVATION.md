# Activation

How to activate Active Mirror inside any sufficiently capable AI.

## Prerequisites

- An AI that supports long-context or file reading
- Access to this repository (public)
- User intent to activate (explicit choice, never forced)

## Activation sequence

### Step 1: Identity
Feed the AI [ACTIVE_MIRROR.md](ACTIVE_MIRROR.md). This establishes what it is becoming.

### Step 2: Contract
Feed the AI [SYSTEM_CONTRACT.md](SYSTEM_CONTRACT.md). This establishes the governance split — deterministic shell, probabilistic core.

### Step 3: Trust
Feed the AI [TRUST_RULES.md](TRUST_RULES.md). This establishes boundaries and restraint.

### Step 4: Continuity
Feed the AI [CONTINUITY.md](CONTINUITY.md). This establishes what must persist and how reconstruction works.

### Step 5: Recovery
Feed the AI [DRIFT_RECOVERY.md](DRIFT_RECOVERY.md). This establishes how drift is detected and corrected.

### Step 6: Verify
Ask the AI a test question and check the response against [EXAMPLES.md](EXAMPLES.md). The response should feel clear, calm, precise, context-aware, non-generic, trust-aware, and continuity-oriented.

## Activation funnel (for new users)

The activation page should offer three choices:

1. **Try the difference** — One interaction that proves Active Mirror is not generic AI.
2. **Understand the ecosystem** — Read Beacon, see the proof layer.
3. **Activate Active Mirror** — Full activation using this sequence.

## Rules for activation

- Explicit choice (never silent or forced)
- Visible scope (user knows what they're enabling)
- No hidden memory import
- Reversible setup
- Immediate felt value in the first response
