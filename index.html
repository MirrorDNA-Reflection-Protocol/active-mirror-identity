Verify Locally

Any signed file can be verified against the Ed25519 public key using standard tools.

# 1. Get the public key
PUB="382af5cd3016aee38eb1bc21f2516105d4534e05df0fb01a16f3596c6dd96cfa"

# 2. Check the artifact against its .sig sidecar
python3 -c "
  import json, hashlib, sys
  from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PublicKey
  sig = json.load(open(sys.argv[1]+'.sig'))
  data = f\"{sig['sha256']}:{sig['file']}\".encode()
  pub = Ed25519PublicKey.from_public_bytes(bytes.fromhex('$PUB'))
  pub.verify(bytes.fromhex(sig['sig']), data)
  print('VALID')
" your_file.pdf

# 3. Or use GPG for documents signed with the sovereign key
gpg --verify document.pdf.sig document.pdf
